# Apple Store Management System

## Overview
A Python-based Apple Store management system developed as an academic project.
The project focuses on core logic and data handling without a frontend interface.

## Features
-	Viewing item lists and product details 
-	Purchasing phones and other accessories 
-	Handling repairs and warranty claims 
-	Processing returns 
-	Old phone exchange
-	Billing and receipt generation 
-	Warranty and insurance tracking 
-	Inventory management

## Tech Stack
- Python

## How to Run
1. Clone the repository
2. Make sure Python is installed
3. Run the following command in the project folder:
